# Reverse SPES 원문판 v1.1

리버스페스 1강(89p), 2강(110p)과 사용자 제공 확대 캡처를 기준으로 만든 원문 재현/진단용 테스트방입니다.

## 이번 v1.1에서 원문 확정 반영
- 리버스 피보나치 수식 완전 반영
- M지표(R) 수식 반영
- RS20 핵심 매수조건 반영
- RS3 1/2차 매수, +4% 익절, 70선 손절 수식 반영
- RS3 M지표 200억을 **필수조건이 아닌 '확률 UP'** 요소로 수정
- RS3 제외조건/기간손절 문구 반영
- J6 방식처럼 첫 탈락사유 퍼널 진단 추가

## 중요한 원문 보존 사항
강의의 명칭상 `0.382` 선은 `저점 + 변동폭*0.618`, `0.618` 선은 `저점 + 변동폭*0.382`입니다. 일반적인 명칭으로 임의 교정하지 않습니다.

## 아직 자동화 확정이 필요한 항목
RS20: 세력/수급세력주 자동분류, `38선 부근` 범위, `첫 눌림` 판정, O/△/X 의미.

RS3: `50선 근처`, `크게 반등`, `투상 이상`, 신규상장 제외기간, `2일 안 반등`의 정확한 수치 판정.

이 항목들은 임의 파라미터를 넣지 않고 입력 필드/보류 상태로 유지합니다.

## 실행
```bash
pip install -r requirements.txt
pytest -q
python src/run_diagnostic.py sample.csv --strategy rs20
python src/run_diagnostic.py sample.csv --strategy rs3
```
