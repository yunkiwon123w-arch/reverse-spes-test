Reverse SPES - RS20 원문판 후보 Funnel v1

[목적]
원문에서 확정 가능한 RS20 조건만 코드로 고정하고,
미정의 조건은 임의로 수치화하지 않는 진단용 1차 파일입니다.

[현재 자동판정]
- M지표 >= 200억원
- M지표 / 거래대금 >= 20%
- Reverse Fibonacci 38선 가격 계산

[현재 자동판정하지 않음]
- 세력주 / 수급세력주
- '38선 부근' 허용범위
- 3파 차트의 기계적 정의
- 신규상장의 기간 정의

[실행]
run_rs20_source_funnel_v1.bat 더블클릭

[예상]
샘플 3건을 검사하고 rs20_source_funnel_v1_sample.csv를 생성합니다.

주의:
이 버전은 구조 검증용 1차판입니다.
아직 Kiwoom 전종목 데이터 연결/실제 주문 기능은 없습니다.
